# JavaProjects

This repository contains Java fundamentals and mini projects developed to strengthen core programming concepts and problem-solving skills.

## Repository Structure

### Basic
The **Basic** package covers core Java concepts, including:
- Variables and Data Types
- Type Casting
- Operators
- Conditional Statements
- Loops
- Methods
- Arrays
- Object-Oriented Programming (Classes, Objects, Encapsulation)

This section focuses on building a strong foundation in Java.

### Projects
The **Projects** package contains practical Java applications created using core concepts.  
Each project is designed to improve logical thinking, code structure, and real-world problem-solving.

Examples include:
- Student Management System
- Bank Application
- Restaurant Management System
- Calculator with Menu and History

## Purpose
The goal of this repository is to:
- Build a solid understanding of Java fundamentals
- Apply concepts through hands-on projects
- Maintain clean, organized, and version-controlled code

This repository will continue to evolve as more concepts and projects are added.
